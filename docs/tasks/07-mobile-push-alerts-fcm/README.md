# Mobile Push Alerts (FCM)

This folder contains the complete implementation plan, step-by-step setup guides, and technical specifications for integrating **Firebase Cloud Messaging (FCM)** into the mobile app and backend.

- **Status:** 🔴 Not Integrated (In-app fetch only)
- **Goal:** Real background push notifications on phone lock screen (even when app is closed)
- **Cost:** 100% Free (No credit card needed)
