How a bite pin gets on the map
Staff logs bite case Registers location during Form 1
DB stores lat/lng + bite data bite_cases table: lat, lng, category, date
API returns bite records GET /api/bite-cases?from=&to=&category=
Leaflet renders markers Each record → <Marker> on the map
Click marker → popup Patient name, bite category, date, status
