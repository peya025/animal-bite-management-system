# UI Test Guide: Cycle 1 – Audit Logs & Staff Activity Monitoring

## Objective
Verify the end-to-end functionality of staff activity monitoring, filtering, and summary metrics on the web application frontend following the refactoring of `AuditLogController.php` (Single-Clinic installation).

---

## Target Endpoints Verified
- `GET /api/audit-logs` (Filtered and paginated staff activity logs)
- `GET /api/audit-logs/summary` (Daily/weekly action counts, after-hours suspicious activity, and top active user)
- `GET /api/audit-logs/user/{userId}` (Targeted staff user activity history)

---

## Prerequisites
1. Single-clinic deployment running locally (`backend` at `http://127.0.0.1:8000`, `frontend` at `http://localhost:5173`).
2. Logged in as a user with the **Clinic Admin** role (`role: 'admin'`).

---

## Step-by-Step Test Procedure

### 1. Access Staff Activity Page
1. Navigate to the Admin Dashboard.
2. In the navigation sidebar, locate and click **Staff Activity** (route: `/admin/staff-activity` or developer explorer).
3. **Expected Result:**
   - The Activity Dashboard loads smoothly with 4 metric cards at the top:
     - Today's Total Actions
     - This Week's Actions
     - Today's Logins
     - Suspicious After-Hours Actions (based on clinic operating hours)
   - The Most Active Staff Member section displays the top user with action counts and role details.
   - The audit log data table displays recent staff events sorted descending by timestamp.

---

### 2. Verify Filter Controls
1. **Filter by Staff Member:**
   - Open the "User" dropdown and select a specific staff member (e.g., a Treatment Nurse or Clinic Admin).
   - **Expected Result:** The table updates to show only events generated by that selected user.
2. **Filter by Action Type:**
   - Open the "Action" dropdown and choose `login`.
   - **Expected Result:** Only login events are displayed, decorated with the green login badge.
3. **Filter by Date Range:**
   - Select today's date in both `Date From` and `Date To`.
   - **Expected Result:** Only activities logged today are displayed.
4. **Search by Keyword / IP:**
   - Enter an IP address or descriptive term (e.g., `127.0.0.1` or `inventory`) in the Search input.
   - **Expected Result:** The table dynamically filters to entries matching either the IP address or description.

---

### 3. Verify Pagination
1. Set the page size or navigate to subsequent pages if total logs exceed the page threshold.
2. **Expected Result:** Correct pagination controls (page numbers, next/prev buttons, and total records count).

---

### 4. Verify Role Authorization
1. Log out from the Admin account.
2. Log in as a Nurse or non-admin staff member.
3. Attempt to access `/admin/staff-activity` or direct API request to `/api/audit-logs`.
4. **Expected Result:** HTTP 403 Forbidden with uniform error response. Non-admin users are strictly denied access to audit logs.
